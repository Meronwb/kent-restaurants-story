
# Mapping Cultural Food Spaces in Kent

# Live site: 

https://meronwb.github.io/kent-restaurants-story/

## Project Overview
This project is a geo-narrative map that explores cultural food spaces in Kent, Washington. The goal of this project is to show how restaurants can represent cultural diversity and community identity. By mapping locations within this community popular cultural food spots, this project highlights how food reflects patterns of immigration and the presence of different cultural groups within the city. These restaurants are not only places to eat, but also serve as important social and cultural spaces.

## Features
- Interactive Mapbox map displaying cultural food locations
- GeoJSON dataset of restaurants in Kent
- Scroll-based storytelling using Scrollama
- Multiple scenes explaining diversity, location, and community atmosphere

## Data Sources
- Restaurant locations collected manually using Google Maps
- Coordinates gathered for each location within Kent, Washington
- Data formatted into GeoJSON for mapping

## Methods
The project was created using Mapbox GL JS for the interactive map and Scrollama for the storytelling structure. Restaurant data was collected and organized into a GeoJSON file, then styled and displayed on the map. Each point represents a cultural food location categorized by cuisine type.
